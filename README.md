### 🚀 Featured projects

**[Apna Dhanda](https://github.com/Krishpatil16/apna-dhanda)**: a multi-shop app for local kirana stores and salons, with customer ordering, a shopkeeper panel and an owner console. Runs on Cloudflare Workers + D1.
Live: [apnadhanda.krishpatil.workers.dev](https://apnadhanda.krishpatil.workers.dev)

**[VARSHANETRA](https://github.com/Krishpatil16/varshanetra)**: an AI-powered heavy-rainfall early warning and flood prediction system, with risk maps, forecasts and alerts. Built with FastAPI, React, Leaflet, machine learning and GIS.

**[support-tickets](https://github.com/Krishpatil16/support-tickets)**: a Python (Streamlit) app to create, manage and visualize support tickets.
